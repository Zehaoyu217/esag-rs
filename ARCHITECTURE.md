# esag — architecture and implementation contract

> This was the contract the modules were built against. Deviations made
> during implementation are listed at the end; see `docs/MATH.md` for the
> mathematics as implemented and `README.md` for the API.

Rust port + re-engineering of the ESAG R code in `Zehaoyu217/ESAG`
(`ESAG_Project2.R` is the authoritative, general-`d` version; `ESAG.R` is an
older variant). Reference R sources are mirrored under `reference/r/`.

Goals, in priority order:
1. **Numerical parity** with the R code (same parameterization, same density,
   same residuals/tests), verified against fixtures generated by running the R
   code (`tests/fixtures/*.json`).
2. **Speed**: exact gradients via forward-mode AD (dual numbers) instead of R's
   finite differences, L-BFGS instead of BFGS, no matrix materialisation in the
   hot loop, rayon parallelism over observations and bootstrap replicates.
3. **A scikit-learn-style API**: `EsagRegressor::new().with_*().fit(&X, &Y)` →
   fitted model with `predict`, `predict_distribution`, `score`, `residuals`,
   `summary`, plus inference helpers (GoF, prediction regions, hypothesis tests).

## Notation (must match the R code exactly)

* `d` = ambient dimension, data live on S^{d-1} (unit vectors in R^d), d ≥ 3.
* `mu ∈ R^d`, not necessarily unit; `mu_hat = mu/|mu|`.
* `gamma ∈ R^g`, `g = gamma_len(d) = (d-2)(d+1)/2`  (d=3→2, d=4→5, d=5→9, d=6→14).
* `eta = (mu, gamma) ∈ R^B`, `B = eta_len(d) = d + g = (d²+d-2)/2` (3→5, 4→9, 5→14, 6→20, 7→27, 8→35).
* `p = d-1` = number of non-unit eigenvalues.

### gamma → (lambda, theta, phi)   (R: `parameter`)
Group gamma into `d-2` consecutive groups; group `i` (1-based, i=1..d-2) has
`i+1` entries and starts at 0-based offset `i(i+1)/2 - 1`:
group 1 = gamma[0..2], group 2 = gamma[2..5], group 3 = gamma[5..9], …
(R: `c1 = i(i+1)/2`, `c2 = (i+1)(i+2)/2 - 1`, 1-based inclusive.)

For group `i` with entries `G = (G_1..G_n)`, `n = i+1`:
* `K_i = |G| + 1`  (Euclidean norm plus one).
* `theta_i = atan2(G_n, G_{n-1})`  (R uses acos with a sign; identical to atan2;
  returns 0 if both are zero).
* for `j = 1..n-2`: `phi_{i,j} = acos( G_j / sqrt(sum_{k=j}^{n} G_k²) )`, or 0 when
  that sum is 0.  Group 1 (n=2) contributes no phi.  phis are concatenated in
  group order: total `(d-2)(d-3)/2`.
* `lambda_1 = ( prod_{i=1}^{d-2} K_i^{(d-1-i)} )^{-1/(d-1)}`,
  `lambda_j = K_{j-1} · lambda_{j-1}` for j = 2..d-1.   ⇒ prod lambda_j = 1,
  lambda_1 ≤ lambda_2 ≤ … ≤ lambda_{d-1}.
* d = 3: `K = 1 + sqrt(g1²+g2²)`, `lambda = (K^{-1/2}, K^{1/2})`, `theta_1 = atan2(g2, g1)`.

### Orthonormal basis of R^d containing mu_hat   (R: `ONB`, Project2 version)
Returns a d×d matrix `U` with **columns** `u_1..u_d`; `u_d = mu_hat`
(`e_d` if mu = 0). `u_1 = (-mu_2, mu_1, 0, …, 0)/sqrt(mu_1²+mu_2²)`, or `e_1` if
that norm is 0. For `i = 3..d`: `s = sum_{k<i} mu_k²`; if `s = 0` then
`u_{i-1} = e_{i-1}`, else `u_{i-1} = (mu_1 mu_i, …, mu_{i-1} mu_i, -s, 0, …, 0)` normalised
(the `-s` sits in coordinate `i`).

### Rotation R ∈ SO(d-1)   (R: `rotation`)
Let `Lo(θ)` be the (d-1)×(d-1) identity with the (1,2) block replaced by
`[[cos θ, -sin θ], [sin θ, cos θ]]`, and `P_{a,a+1}(φ)` the identity with the
(a, a+1) block replaced by `[[cos φ, -sin φ], [sin φ, cos φ]]` (1-based a).
Then, with `R = I`:
```
for m in 1..=d-3:
    La = I
    for j in 1..=d-m-2:
        idx = 1 - j + (d-m-1)(d-m-2)/2        # 1-based into the phi vector
        La = La · P_{j+1,j+2}(phi[idx])
    R = R · Lo(theta[d-m-1]) · La
R = R · Lo(theta[1])
```
For d = 3 this is just `R = Lo(theta_1)`. Implementations may apply these
plane rotations to vectors instead of forming matrices, but a
`rotation_matrix` function returning the full matrix (row-major) must exist
for testing.

### Covariance   (R: `covariance_matrix_gamma(mu, gamma, p)`)
`E = U[:, 1..d-1] · R` (d×(d-1)); `P = [E | mu_hat]` (d×d orthogonal);
`V^s = P · diag(lambda_1^s, …, lambda_{d-1}^s, 1) · P^T`. So `V mu = mu`, `|V| = 1`.
Hot-loop form: with `v_j` = column j of E, `y^T V^{-1} y = Σ_j (v_j·y)²/lambda_j + (mu_hat·y)²`.

### Log-density   (R: `log_likelihood(Bx_i, y_i)`), y a unit vector
```
q     = y^T V^{-1} y
alpha = (y·mu) / sqrt(q)
log f = -(p/2) log(2π) - (d/2) log q + ½(alpha² - |mu|²) + log M_p(alpha),  p = d-1
M_1(a) = a Φ(a) + φ(a);  M_2(a) = (1+a²) Φ(a) + a φ(a);  M_k(a) = a M_{k-1}(a) + (k-1) M_{k-2}(a)
```
**Stability requirement** for `log M_p(a)`: for `a > -8` use the recursion with
`Φ` from `erfc` (full relative accuracy). For `a ≤ -8` use the asymptotic
series in log form:
`M_p(a) = φ(a) · Σ_{k≥0} (-1)^k (p+2k)! / (2^k k! |a|^{p+2k+1})`, summing until
terms stop decreasing (≤ 40 terms), so `log M_p(a) = log φ(a) + log S`
(`log φ(a) = -a²/2 - ½ log 2π` never underflows). Both branches must be written
generically over `Scalar` so dual numbers differentiate them.

Regression: `eta_i = B x_i`, `B` is `B × (p_x)` (p_x = number of columns of the
design matrix incl. intercept). R stores B column-major with rows ordered
(mu_1..mu_d, gamma_1..gamma_g). Joint log-likelihood = Σ_i log f(y_i; eta_i).
Gradient: `∂LL/∂B = Σ_i g_i x_iᵀ`, where `g_i = ∂ log f(y_i; eta)/∂eta` — the
per-observation gradient is obtained with `Dual<B>` (forward-mode AD).

### Residuals and inference (R: `residual_T`, `Bootstrap_GoF`, `Confidence_Region`,
`Prediction_Region`, `stats_gamma`, `mome_stats`, `hypothesis_testing_*`)
* `r_i = (I - mu_hat mu_hatᵀ) y_i`;  `Q_i = r_iᵀ V^{-1} r_i`;
  `T1_i = (|mu|² + Σ_j lambda_j + 1) · Q_i`, reference distribution χ²_{d-1}.
* GoF: `stat = KS p-value of T1 vs χ²_{d-1}`; parametric bootstrap: simulate
  `Y_b` from the fitted model at the observed X, refit (start at the MLE),
  recompute the stat; `p = mean(stat_obs ≥ stat_boot)`.
* Confidence region at (mu, gamma): sample m points from ESAG(mu, gamma),
  `q = (y - mu_hat)ᵀ V^{-1} (y - mu_hat)`; prediction region for observation
  `index`: pool `q` from the MLE and from `num_boot` nonparametric bootstrap
  refits (resample rows of (X, Y)); report quantiles (0.95, 0.90, …, 0.70).
* Test statistics (restricted vs full fit): `RoC = mean_i |mu_a,i| / |mu_0,i|`,
  `D = mean_i (2 - cos∠(mu_0,i, mu_a,i)) · RoC_i`,
  `M = Σ_k ( mean_i ( y_ik² - E[Y_k²; mu_0,i, gamma_0,i] ) )²` with the second
  moment by Monte Carlo (`mc` draws), `LR = -2 (ll_0 - ll_a)`. Null distribution
  by parametric bootstrap from the restricted fit; `p = mean(stat_obs < stat_boot)`.
  Restricted fits: isotropy (all gamma rows = 0), `alpha_k = 0` (mu rows of
  covariate k), `beta_k = 0` (gamma rows of covariate k). Implement these via a
  generic free-parameter mask.
* Known bug in the R code to NOT replicate: in `hypothesis_testing_*` the
  bootstrap sample uses `Bx[i, ]` (bootstrap counter) instead of `Bx[j, ]`
  (observation). The Rust version simulates `Y_b[j] ~ ESAG(eta_j)`.

Data matrices use `nalgebra::DMatrix<f64>` with one observation per ROW
(Y: n×d, X: n×p). Internally the hot loops work on `&[f64]` slices.

## Conventions
* `#![deny(unsafe_code)]`-level hygiene; no `unsafe`.
* Public items documented; `cargo clippy -- -D warnings` clean; `cargo fmt`.
* Tests: unit tests next to the code, parity tests in `tests/` reading
  `tests/fixtures/*.json` with `serde_json`. Tolerances: 1e-10 relative for
  deterministic quantities (parameterization, density), looser for MLEs
  (R's BFGS with numerical gradients is only accurate to ~1e-3; compare
  log-likelihood values and require Rust's maximum ≥ R's minus 1e-6).
* RNG: `rand_chacha::ChaCha8Rng`, seeded per bootstrap replicate as
  `seed_from_u64(seed.wrapping_add(replicate as u64))` so results do not depend
  on thread count. (rand 0.10 / rand_distr 0.6 — check the exact API in
  `~/.cargo/registry/src/*/rand-0.10*/` before using it.)

## Deviations made during implementation

* `log M_p` for `alpha < -2` uses a backward continued fraction instead of the
  asymptotic series; the series is not accurate enough at `|alpha| = 8` for
  `p ≥ 5`.
* L-BFGS also accepts Hager–Zhang approximate-Wolfe points, because a
  function-value line search stalls at `‖g‖ ≈ sqrt(2 λ_max ulp(f))`.
* Fits are canonicalised under the exact symmetry `γ group 1 → −γ group 1`
  (`regression::canonicalize_coef`).
* `Init::Auto` (default) runs the data-driven and R-style starts. A fit only
  counts as converged if the mean per-observation gradient is ≤ 1e-3.
* Goodness of fit defaults to the paper's two-sample statistic (Algorithm 1);
  the R code's one-sample χ² variant is `GofMethod::OneSampleChiSquare`.
* `M` is the squared norm, as in the R code and the published tables.
* Hypothesis-test refits take the best of two starts, which removed an
  over-rejection of the bootstrap LR test.
